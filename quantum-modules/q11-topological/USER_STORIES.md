# Topological Qubits — User Stories

## Overview
Majorana fermions, non-Abelian anyons, intrinsic error protection, topological gates.

## User Stories

### US-01: researcher — simulate topological qubit properties
**As a** researcher, **I want** simulate topological qubit properties **so that** I understand intrinsic error protection.

**Acceptance Criteria:**
- [ ] Error rate vs transmon compared
- [ ] Topological gap computed
- [ ] Braiding operations shown

## Input / Process / Output

| Stage | Description |
|-------|-------------|
| **Input** | Topological gap energy, braiding sequence |
| **Process** | Majorana Hamiltonian, anyon braiding simulation, error rate calculation |
| **Output** | Logical error rate, protection factor, gate fidelity |
