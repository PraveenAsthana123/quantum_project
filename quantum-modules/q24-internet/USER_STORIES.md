# Quantum Internet — User Stories

## Overview
QKD networks, BB84, E91, quantum key rate vs distance, network topology design.

## User Stories

### US-01: network architect — design a 5-node QKD network
**As a** network architect, **I want** design a 5-node QKD network **so that** I can distribute secure keys across a city.

**Acceptance Criteria:**
- [ ] Key rates computed per link
- [ ] Topology optimized
- [ ] Security proof verified

## Input / Process / Output

| Stage | Description |
|-------|-------------|
| **Input** | Network topology, fiber length, detector efficiency |
| **Process** | BB84/E91 simulation, sifting, error correction, privacy amplification |
| **Output** | Secret key rate, QBER, network topology map |
