# Quantum Repeaters — User Stories

## Overview
Entanglement distribution, purification, quantum memory requirements, GHZ-based repeaters.

## User Stories

### US-01: network engineer — design 200km quantum repeater chain
**As a** network engineer, **I want** design 200km quantum repeater chain **so that** I can distribute entanglement over long distances.

**Acceptance Criteria:**
- [ ] 3-node chain simulated
- [ ] Purification applied
- [ ] End-to-end fidelity > 0.9

## Input / Process / Output

| Stage | Description |
|-------|-------------|
| **Input** | Link distance, raw fidelity, memory time, purification rounds |
| **Process** | Entanglement generation, purification protocol, swapping |
| **Output** | End-to-end fidelity, secret key rate, resource requirements |
