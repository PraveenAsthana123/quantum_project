# Quantum Sensing — User Stories

## Overview
Heisenberg limit, SQL comparison, NV center magnetometry, gravitational wave sensing.

## User Stories

### US-01: physicist — demonstrate Heisenberg limit advantage
**As a** physicist, **I want** demonstrate Heisenberg limit advantage **so that** I show quantum sensing beats classical.

**Acceptance Criteria:**
- [ ] SQL = 1/√N for N probes
- [ ] HL = 1/N, N-fold improvement
- [ ] Experimental feasibility shown

## Input / Process / Output

| Stage | Description |
|-------|-------------|
| **Input** | Number of probe states N, measurement protocol |
| **Process** | Quantum Fisher information, Cramér-Rao bound, entangled probe preparation |
| **Output** | Precision estimate, improvement factor vs SQL, application relevance |
