# Silicon Spin Qubits — User Stories

## Overview
Electron spin qubits in silicon, single-qubit gates, spin-spin coupling, readout.

## User Stories

### US-01: hardware physicist — simulate spin-1/2 in magnetic field
**As a** hardware physicist, **I want** simulate spin-1/2 in magnetic field **so that** I understand qubit operations.

**Acceptance Criteria:**
- [ ] Pauli operators applied correctly
- [ ] Expectation values match theory
- [ ] Rabi oscillation shown

## Input / Process / Output

| Stage | Description |
|-------|-------------|
| **Input** | Hamiltonian parameters, drive frequency, pulse duration |
| **Process** | Time evolution, Bloch sphere dynamics, readout simulation |
| **Output** | Qubit state, gate fidelity, T1/T2 times |
