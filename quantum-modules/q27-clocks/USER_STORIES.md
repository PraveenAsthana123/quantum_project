# Quantum Optical Clocks — User Stories

## Overview
Sr optical lattice clocks, fractional frequency uncertainty, relativistic corrections.

## User Stories

### US-01: physicist — compare optical vs microwave clocks
**As a** physicist, **I want** compare optical vs microwave clocks **so that** I understand why optical clocks are better.

**Acceptance Criteria:**
- [ ] Sr clock at 4.29×10¹⁴ Hz simulated
- [ ] 10² improvement over Cs shown
- [ ] Relativistic correction computed

## Input / Process / Output

| Stage | Description |
|-------|-------------|
| **Input** | Atomic species, transition frequency, interrogation time |
| **Process** | Stability model, fractional frequency uncertainty, Allan deviation |
| **Output** | Uncertainty floor, stability curve, comparison to standards |
